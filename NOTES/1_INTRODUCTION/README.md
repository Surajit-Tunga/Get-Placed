## About JAVA
- Developed by James Gosling at Sun Microsystems (Early 90s).
- Original name "Oak", later renamed to JAVA in 1995.
- Introduced "Write Once, Run Anywhere", concept with cross-platfrom compatibility.
- Java Program in converted into ByteCode, This Bytecode will run on machine (converted into machine code by JVM).
- Bytecode is an intermediate representation of code, typically generated during compilation.
- Secure because of code running on Virtual Machine.
- Developed with vision of backward compatibility. (new versions can work with older versions).
- JAVA is robust due to strong memory management, exception handling and type checking mechanisms, which help in preventing system crashes & ensuring  reliable performance. 
- Multithreading in programming is the ability of a CPU to execute multiple thereads concurrently, allowing more efficient processing.
- Java is architecturally neutral because its compiled code (bytecode) can run on any device with a Java Virtual Machine (JVM), regardless of the underlying hardware architecture.
- Java combines high performance with interpretability, as its bytecode is interpreted by the Java Virtual Machine (JVM), which employs Just-In-Time (UIT) compilation for efficient and fast execution.
- Java is inherently distributed, designed to facilitate network-based application development and interaction, seamlessly integrating with Internet protocols and remote method invocation.
