# LOGIC BUILDING

- Logic building means to create a clear, step-by-step methods to solve any problem with some rules and principles.
- At first read & understand the problem then think about input and output cases for the problem. After that solve that problem in the very basic way you can then optimize it. 

[Ref](https://www.geeksforgeeks.org/dsa/logic-building-problems/)
